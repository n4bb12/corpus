# Coding Challenge – NotebookLM-Klon

## Aufgabe

Baue einen Klon von [Google NotebookLM](https://notebooklm.google.com).

Umsetzung, Umfang und Struktur sind vollständig dir überlassen. Die Nutzung von AI-Tools ist ausdrücklich erwünscht.

## Einreichung

Damit wir nachvollziehen können, wie du vorgegangen bist, sende uns zusätzlich entweder:

1. ein Loom-Video oder
2. die Agent Session.

Eine der beiden Varianten reicht aus.

Antworte auf die E-Mail mit:

- einem Link zum Live Deployment,
- einem Link zum GitHub-Repository und
- dem Loom-Video oder der Agent Session.

Sobald wir dein Ergebnis gesichtet haben, melden wir uns mit den nächsten Schritten.
